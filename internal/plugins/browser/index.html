What this is (and what it is not)

        

            
This is a diagnostic tool for a small host (4 weak cores, ~3 GB RAM). Every browser instance costs
               roughly 250-400 MB of RAM, and screenshots are JPEG frames, not video — do not use it to watch films.

            
    
                
  • Chromium runs on the host, so it uses the host network (and your local bypass proxy if selected).
    • 
                
  • Nothing is proxied through PodmanView and no external HTML is embedded as an iframe.
    • 
                
  • Instances start lazily, one per network profile, and stop after the idle timeout or when the plugin
                    is disabled.
    • 
                
  • Requires Chromium on the host: apt-get install -y chromium fonts-dejavu-core.
    • 
                
  • Every endpoint here requires an authenticated PodmanView session or the API token.
