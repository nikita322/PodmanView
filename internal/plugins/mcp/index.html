MCP Server

Connection

Endpoint URL: /mcp
Transport: Streamable HTTP (MCP)
Authentication: Admin only — use Authorization: Bearer <PODMANVIEW_API_TOKEN>, ?api_token=..., or an admin session cookie.

Available Tools

system.infoHost OS, kernel, arch, Podman version, uptime
system.resourcesCPU, memory, disks, temperatures
system.processesList running processes
system.kill_processSignal a process by PID
systemd.list_unitsList systemd units
systemd.manage_unitStart/stop/restart/enable/disable units
network.interfacesInterfaces, IPs, listening sockets
packages.listInstalled packages (apt/dnf)
packages.installInstall packages
packages.updateUpgrade all packages
command.runRun a shell command
power.rebootReboot host
power.shutdownShut down host
podman.listContainers and images
podman.manageStart/stop/restart/remove containers
podman.logsContainer logs
logs.journalctlSystemd journal logs
